# OKF Memory Bundle

This bundle contains the full agent memory exported from Mem0 via Memanto's
`memanto migrate mem0` + `memanto memory export --okf` pipeline.

- **Source:** Mem0 account (3 entities, 17 memories)
- **Migrated:** via `memanto migrate mem0 --file showcase/mem0_export.json`
- **Exported:** via `memanto memory export --okf`
- **Format:** Open Knowledge Format (OKF) — plain Markdown with YAML frontmatter
- **Portable:** This bundle can be imported into any OKF-compatible system

See `memories/` for individual memory files.
