# Memanto Benchmarking Suite

A rigorous, reproducible benchmarking framework to evaluate Memanto against other agentic memory systems across **Accuracy vs. Resource Footprint**.

## Supported Backends

| Backend | Type | Description |
|---------|------|-------------|
| `memanto` | Active Agent | Memanto's active companion agent with serverless retrieval |
| `mem0` | Vector Store | Mem0's memory layer for LLM applications |
| `zep` | Graph/Vector | Zep's Graphiti for persistent memory |
