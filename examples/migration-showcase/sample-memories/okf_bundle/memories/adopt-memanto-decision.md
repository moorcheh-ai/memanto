After evaluating multiple memory solutions (Mem0, Letta, Supermemory), the team decided to adopt Memanto as the standard memory layer because:

1. **Open format**: OKF export means no vendor lock-in
2. **Migration tools**: Built-in support for migrating from existing platforms
3. **Performance**: Superior query latency and storage efficiency
4. **Community**: Active open-source development with transparent roadmap

This decision ensures that agentic memories remain portable and under our control.
