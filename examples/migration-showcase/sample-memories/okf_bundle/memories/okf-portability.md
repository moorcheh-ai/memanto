The Open Knowledge Format (OKF) is a vendor-neutral, open standard for representing agentic memories as plain markdown files with YAML frontmatter. This format ensures that agent memories are never locked into a single platform.

OKF bundles are:
- **Git-friendly**: Plain markdown files work with any version control system
- **Human-readable**: No special tools needed to view or edit memories
- **Lossless**: Unmapped fields are preserved during import/export
- **Portable**: Works with any OKF-compatible memory platform
