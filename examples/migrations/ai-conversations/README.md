# AI Conversation Migration → Memanto → OKF Bundle

> **Bounty Submission** for [The Great Memory Migration](https://github.com/moorcheh-ai/memanto/issues/1609) — $200 USD

## What This Does

Migrates your **ChatGPT** and **Claude** conversation history into Memanto, then exports it as a portable **OKF (Open Knowledge Format)** bundle that any AI system can read.

### The Problem

When you switch AI assistants, your conversation history — the memories, preferences, and context you've built — is trapped in the source platform. ChatGPT exports are JSON trees. Claude exports are flat JSON. Neither is portable or reusable.

### The Solution

This adapter:
1. **Parses** ChatGPT's tree-structured exports and Claude's flat JSON exports
2. **Extracts** user messages as semantically rich memories with provenance metadata
3. **Defers classification** to Memanto's ingestion service (type is set to `None` for auto-classification)
4. **Imports** into Memanto via the batch API
5. **Exports** as a human-readable OKF bundle (markdown + manifest JSON)
6. **Validates** recall parity — ensures key facts survive the migration

## Quick Start

```bash
# Install dependencies
pip install memanto rich

# Run with sample data (no API key needed)
python migrate.py --demo

# Run with your own export
python migrate.py --source chatgpt --export ./path/to/chatgpt_export.json
python migrate.py --source claude  --export ./path/to/claude_export.json
```

## Getting Your Export

### ChatGPT
1. Go to [Settings → Data Controls → Export Data](https://chatgpt.com/#settings/DataControls)
2. Click "Export" — you'll receive a ZIP via email
3. Unzip and find `conversations.json`

### Claude
1. Go to [Settings → Account → Export Data](https://claude.ai/settings)
2. Click "Export" — you'll receive a ZIP via email
3. Unzip and find `conversations.json`

## CLI Usage (Memanto)

After the PR is merged, you can use Memanto's built-in CLI:

```bash
# Dry run — preview mapped memories
memanto migrate conversations --source chatgpt ./chatgpt_export.json --dry-run

# Migrate
memanto migrate conversations --source claude ./claude_export.json

# With specific agent
memanto migrate conversations -s chatgpt ./export.json --agent my-agent
```

## Validation

```bash
# Run recall-parity tests
python validation/validate.py --source chatgpt --export ./sample_data/chatgpt_export.json
python validation/validate.py --source claude  --export ./sample_data/claude_export.json

# Validate an existing OKF bundle
python validation/validate.py --validate-okf --okf-dir ./okf_bundle
```

## Architecture

```text
Source Export (JSON)          Memanto Schema              OKF Bundle
┌─────────────────┐          ┌─────────────────┐         ┌─────────────────┐
│ ChatGPT tree    │──map────▶│ memories[]      │──export▶│ manifest.json   │
│ Claude flat     │          │ {               │         │ memories/*.md   │
│                 │          │   title,        │         └─────────────────┘
│                 │          │   content,      │
│                 │          │   type,         │
│                 │          │   tags,         │
│                 │          │   provenance    │
│                 │          │ }               │
└─────────────────┘          └─────────────────┘
```

## Memory Classification

The adapter sets `type: None` for all migrated memories, deferring classification to Memanto's ingestion service. This ensures consistent type assignment across all memory sources.

## Sample OKF Bundle

The `okf_bundle/` directory demonstrates the output format:

```text
okf_bundle/
├── manifest.json          # Metadata, memory index, version
└── memories/
    ├── mem_0000_Building_a_REST_API_with_FastAPI.md
    ├── mem_0001_React_TypeScript_State_Management.md
    └── mem_0002_Docker_Compose_for_Development.md
```

Each memory file is human-readable markdown with metadata headers.

## Testing

The validation suite checks:
1. **Golden fact recall** — key keywords from the source export must appear in migrated memories
2. **Structural integrity** — OKF bundle has valid manifest, all referenced files exist
3. **Content quality** — migrated memories have sufficient length and proper metadata
