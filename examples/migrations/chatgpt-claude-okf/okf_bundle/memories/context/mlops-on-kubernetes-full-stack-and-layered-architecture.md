User is researching MLOps on Kubernetes at scale. The agreed layered stack is: (1) Infrastructure: GPU node pools, NVIDIA device plugin/GPU Operator, object storage. (2) Scheduling: Kueue, Volcano, KAI Scheduler. (3) Data/Features: Feast, Spark, Airflow, DVC. (4) Training: Kubeflow Trainer v2 (unified TrainJob API), Ray/KubeRay, MLflow. (5) Pipeline orchestration: Kubeflow Pipelines or Argo Workflows. (6) Serving: KServe, BentoML, Ray Serve, vLLM for LLMs. (7) Observability: Prometheus, Grafana, Evidently, ArgoCD for GitOps.
