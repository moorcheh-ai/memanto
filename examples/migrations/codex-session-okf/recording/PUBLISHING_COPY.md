## LinkedIn post

Agent memory creates switching costs when useful context is trapped in a
proprietary schema.

I built a reproducible migration path that converts a genuine Codex session
into privacy-filtered Open Knowledge Format, imports it into Memanto, validates
the same questions after migration, and exports everything back to readable
Markdown.

The result: 4/4 memories imported, zero failures, all three expected answers
ranked first, and all four memories exported back to OKF.

The important product boundary is privacy: reusable user and assistant messages
are portable memory; system prompts, reasoning, tool calls, credentials, and
transport metadata are not.
