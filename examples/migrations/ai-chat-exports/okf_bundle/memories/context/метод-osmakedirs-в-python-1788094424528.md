# Метод os.makedirs в Python

**User:** Что делает метод osmakedirs

**Assistant:** Вероятно, ты имела в виду метод `os.makedirs()` из модуля `os` в Python — такой, как `os.makedirs(path)` .

### Что делает `os.makedirs()` :

Метод `os.makedirs()` **создаёт директории рекурсивно** , то есть **всю цепочку вложенных папок** , если они ещё не существуют.

### Пример:

```plaintext
import os

os.makedirs("папка1/папка2/папка3")
```

Если этих папок ещё нет, Python создаст их все:

```plaintext
папка1/
└── папка2/
 └── папка3/
```

### Дополнительные параметры:

```plaintext
os.makedirs(name, mode=0o777, exist_ok=False)
```

* `name` — путь к создаваемой директории

* `mode` — права доступа (по умолчанию 0777, как в Unix)

* `exist_ok=True` — **не вызывает ошибку** , если директория уже существует. Полезно при повторных запусках.

### Пример с `exist_ok=True` :

```plaintext
os.makedirs("backup/data", exist_ok=True)
```

Если папка уже есть — ошибки не будет.

Если ты писала `osmakedirs` слитно — это просто опечатка. В Python нет встроенного метода с таким именем.

### 📱 Может ли `os.makedirs()` (и вообще Python) работать с папками **на телефоне** ?

#### ✅ **Да, но с оговорками:**

Если ты запускаешь Python **на телефоне** , то он работает с **файловой системой самого телефона** — в пределах тех папок, к которым у него есть доступ.

### 🔧 Как Python может работать на телефоне:

* **Android** :

* Через приложения вроде:

* Pydroid 3 — полноценная среда Python для Android.

* Termux — терминал и пакетный менеджер.

* Python может создавать, читать и удалять файлы **внутри "своего пространства"** — например, в папке `storage/emulated/0/Download` или `data/data/…` .

* **iPhone (iOS)** :

* Более ограничен, но можно установить:

* Pythonista

* Pyto

* Доступ к файловой системе сильно ограничен — в основном в пределах "песочницы" приложения.

### 🧠 Пример на Android с Pydroid:

```plaintext
import os

# создаём папку в папке Downloads (если дали разрешение)
path = "/storage/emulated/0/Download/test_folder"
os.makedirs(path, exist_ok=True)
```

📌 Обрати внимание: тебе нужно будет **разрешить доступ к хранилищу** (Storage) в настройках приложения.

### 🛑 Что не получится:

* Доступаться к системным папкам или внутренним файлам других приложений без root-доступа.

* Изменять структуру «всего телефона» — безопасность ОС не позволит.
