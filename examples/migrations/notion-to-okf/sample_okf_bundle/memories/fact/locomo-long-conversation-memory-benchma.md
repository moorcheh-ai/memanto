LoCoMo is a long-conversation dataset for evaluating memory systems. Contains 50-turn conversations with ground-truth annotations. Used in Memanto vs Mem0 benchmark: Memanto scored R@20=83.3% vs Mem0 63.3%. Dataset is freely available via HuggingFace.
