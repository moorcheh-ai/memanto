# Atlas Relay Memory Fixture

This tiny project is the safe workspace used to produce the committed Codex
memory export. It contains no credentials or personal data and is intentionally
small enough that a real Codex run can inspect it in seconds.

The migration example's source-generation walkthrough records final design
decisions for the open question in `PROJECT.md`, then lets Codex's own memory
pipeline distill that rollout into a stage-one memory record.
