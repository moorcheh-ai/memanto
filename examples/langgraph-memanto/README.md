# LangGraph + Memanto Integration Example

This example demonstrates how to use Memanto as a long-term memory layer for a LangGraph agent.

## Features

- **Cross-Session Memory**: The agent remembers information across sessions
  - Memories stored in one session can be recalled in another
  - Demonstrates persistent memory across agent sessions
  - Allows for continuity in agent behavior and knowledge

- **Showcasing Video**: [Agent Demo Video](https://www.youtube.com/watch?v=example_video)
  
This integration shows how to build a stateful agent that persists knowledge across conversations.
