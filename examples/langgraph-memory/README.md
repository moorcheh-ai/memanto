# Memanto LangGraph Integration Verification

This directory contains a minimal, reproducible script to verify the `MemantoStore` component.

## Running the Verification
1. Set environment variables:
   ```bash
   export MEMANTO_API_KEY="your_key"
   export MEMANTO_URL="http://your-memanto-url:8000"
   ```
2. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the demo:
   ```bash
   python full_pipeline_demo.py
   ```
