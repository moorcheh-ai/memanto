## LinkedIn Post

```text
Excited to share my contribution to the Memanto project — an open-source bounty for migrating AI conversation history.

The Problem:
When you switch between AI assistants (ChatGPT, Claude, etc.), your conversation history — the memories, preferences, and context you've built — is trapped in the source platform.

What I Built:
ChatGPT & Claude migration adapters that:
• Parse ChatGPT's tree-structured conversation exports
• Handle Claude's flat JSON format
• Map conversations to Memanto's memory schema
• Export as portable OKF (Open Knowledge Format) bundles
• Validate recall parity — ensuring key facts survive the migration

Results:
• 100% recall rate on demo data
• Full provenance metadata preserved
• Human-readable markdown output
• Works with both ZIP and JSON exports

This is part of the "Great Memory Migration" bounty ($200) by @moorcheh_ai — making AI memories portable and reusable across platforms.

PR: https://github.com/moorcheh-ai/memanto/pull/1718

#OpenSource #AI #DataPortability #Memanto #Bounty
```
