## Metrics

The benchmark evaluates the core tension of agent infrastructure: **Accuracy vs. Resource Footprint**.

### Accuracy programmatically
- **Recall Accuracy**: Correctly retrieving relevant memories
- **Preference Resolution**: Understanding nuanced, evolving user preferences
- **Context Relevance**: Retrieved memories match the query intent

### Resource Footprint
- **Token Efficiency**: Tokens consumed per memory operation
- **p95 Latency**: 95th percentile response time
- **Memory Usage**: Peak RAM consumption
- **Storage Overhead**: Disk space per 1000 memories
