# Memanto Benchmarking Suite

A rigorous, reproducible benchmarking suite that pits **Memanto** against other dedicated agentic memory frameworks to stress-test their production efficiency across **Accuracy vs. Resource Footprint**.

## Supported Backends

- **Memanto** (this repo) — active companion agent with serverless retrieval
- **Mem0** — vector/graph memory platform
- **Zep / Graphiti** — graph-based memory (placeholder for community implementation)
- **Hindsight** — episodic memory framework (placeholder for community implementation)
- **Letta** — agent with memory (placeholder for community implementation)
